# KV Final Project Report Formatting Guide

This repository was created to share a simple and practical guide for students in preparing and formatting their **Final Project Report / Thesis**.

The main focus of this repository is to help students understand how to correctly set up their report format using Microsoft Word, including headings, page numbering, table of contents, figures, tables, references, and other important formatting elements.

This repository is intended mainly for students of **Kolej Vokasional (KV)** and other technical or diploma-level students who need guidance in preparing their final project report.

---

## Purpose of This Repository

The purpose of this repository is to share the method and steps used to set up the format for a student's final project report.

The materials in this repository can be used as a reference for:

* Setting up Microsoft Word styles and headings
* Creating chapter titles and subheadings
* Setting page margins
* Setting page numbering
* Creating Table of Contents
* Creating List of Figures
* Creating List of Tables
* Inserting figure captions
* Inserting table captions
* Managing section breaks and page breaks
* Setting up front matter pages
* Organising chapters and appendices
* Preparing references and citations
* Improving the overall structure and consistency of a final project report

The aim is to make report preparation easier, more organised, and more professional for students.

---

## Reference and Citation Management

Students are encouraged to use reference management software when preparing their final project report.

Recommended tools include:

### Mendeley

Mendeley can be used to:

* Store journal articles and references
* Insert citations into Microsoft Word
* Automatically generate a bibliography
* Manage research papers and PDF files

### Zotero

Zotero is another useful reference management tool that can be used to:

* Manage references
* Insert citations into Microsoft Word
* Generate reference lists automatically
* Organise journal articles, books, websites, and other sources
* Use different citation styles based on academic requirements

Students may choose either **Mendeley** or **Zotero** depending on their preference and the requirements of their lecturer or institution.

Using a reference manager is highly recommended because it can reduce errors in citation and make the preparation of the reference list much easier.
